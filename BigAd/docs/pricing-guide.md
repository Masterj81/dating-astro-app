# CampaignOS (formerly BigAd) Pricing Guide

Ce document donne une base de prix pour vendre un projet comme CampaignOS :
un outil qui combine software, strategie marketing, media buying logic,
creative operations, exports et diagnostics de lancement.

## Positionnement

Ne pas vendre CampaignOS comme un simple generateur de briefs.

Le vendre comme :

```text
Un systeme qui reduit 2-4 semaines de strategie marketing en 30 minutes,
avec un plan d'execution pret pour createurs, fondateur et media buyer.
```

## References marche

Ordres de grandeur 2026 :

- Developpeur freelance senior : environ $75-$350/h selon niveau, stack et marche.
- Audit ou strategie marketing serieuse : souvent $10k-$25k.
- MVP SaaS custom : souvent $15k-$150k+, selon scope, integrations et qualite production.

## Packages recommandes

### CampaignOS Strategy Sprint

Prix :

```text
$2,500
```

Inclut :

- inputs produit nettoyes
- positionnement
- angles publicitaires
- offer architecture
- landing copy draft
- app store / store copy draft
- export markdown
- 60-90 minutes de walkthrough

### CampaignOS Launch Sprint

Prix :

```text
$7,500
```

Inclut :

- tout le Strategy Sprint
- creative testing matrix
- briefs createurs
- scripts video
- proof asset plan
- tracking readiness plan
- campaign setup recommendations
- kill/scale rules
- 2 semaines de support async

### CampaignOS Growth OS Setup

Prix :

```text
$15,000
```

Inclut :

- tout le Launch Sprint
- plan d'execution sur 30 jours
- dashboard KPI / diagnostic
- next iteration plan
- coordination createur / media buyer
- 4 semaines d'accompagnement

### Custom CampaignOS-like Software Build

Prix minimum :

```text
$50,000+
```

Inclut selon scope :

- app custom
- moteur de generation deterministic
- UI dashboard
- export markdown / PDF
- comptes utilisateurs
- sauvegarde de projets
- billing
- historique
- collaboration
- integrations externes

## Recommandation

Le meilleur pricing de depart :

```text
CampaignOS Strategy Sprint: $2,500

CampaignOS Growth OS Setup: $15,000
Custom CampaignOS-like software build: $50,000+
```
