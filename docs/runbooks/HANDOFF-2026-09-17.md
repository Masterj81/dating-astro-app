Exécuter la requête suivante en lecture seule dans Supabase SQL Editor. Elle ne retourne que des agrégats.

```sql
WITH days AS (
  SELECT generate_series(
    (NOW() AT TIME ZONE 'utc')::date - 1,
    (NOW() AT TIME ZONE 'utc')::date,
    INTERVAL '1 day'
  )::date AS jour_utc
),
events AS (
  SELECT
    (created_at AT TIME ZONE 'utc')::date AS jour_utc,
    event_name,
    COUNT(*) AS total
  FROM public.product_events
  WHERE event_name IN (
    'preview_presented',
    'preview_succeeded',
    'preview_reopened',
    'preview_used_other_target',
    'upgrade_clicked'
  )
    AND created_at >=
      ((NOW() AT TIME ZONE 'utc')::date - 1)::timestamp AT TIME ZONE 'utc'
  GROUP BY 1, 2
),
grants AS (
  SELECT
    usage_date_utc AS jour_utc,
    COUNT(*) AS grants
  FROM public.synastry_free_grant
  WHERE usage_date_utc >= (NOW() AT TIME ZONE 'utc')::date - 1
  GROUP BY 1
)
SELECT
  d.jour_utc,
  COALESCE(g.grants, 0) AS grants,
  COALESCE(MAX(e.total) FILTER (
    WHERE e.event_name = 'preview_presented'
  ), 0) AS preview_presented,
  COALESCE(MAX(e.total) FILTER (
    WHERE e.event_name = 'preview_succeeded'
  ), 0) AS preview_succeeded,
  COALESCE(MAX(e.total) FILTER (
    WHERE e.event_name = 'preview_reopened'
  ), 0) AS preview_reopened,
  COALESCE(MAX(e.total) FILTER (
    WHERE e.event_name = 'preview_used_other_target'
  ), 0) AS preview_used_other_target,
  COALESCE(MAX(e.total) FILTER (
    WHERE e.event_name = 'upgrade_clicked'
  ), 0) AS upgrade_clicked,
  ROUND(
    100.0 * COALESCE(MAX(e.total) FILTER (
      WHERE e.event_name = 'preview_used_other_target'
    ), 0)
    / NULLIF(COALESCE(MAX(e.total) FILTER (
      WHERE e.event_name = 'preview_succeeded'
    ), 0), 0),
    1
  ) AS frustration_pct,
  ROUND(
    100.0 * COALESCE(MAX(e.total) FILTER (
      WHERE e.event_name = 'upgrade_clicked'
    ), 0)
    / NULLIF(COALESCE(MAX(e.total) FILTER (
      WHERE e.event_name = 'preview_used_other_target'
    ), 0), 0),
    1
  ) AS conversion_apres_blocage_pct
FROM days d
LEFT JOIN events e USING (jour_utc)
LEFT JOIN grants g USING (jour_utc)
GROUP BY d.jour_utc, g.grants
ORDER BY d.jour_utc;
```

### Lecture attendue

- `grants` et `preview_succeeded` doivent être cohérents, sans nécessairement être identiques à chaque instant.
- `preview_reopened` compte les lecteurs ayant revu leur cible du jour.
- `preview_used_other_target` mesure les lecteurs bloqués sur une deuxième cible.
- `upgrade_clicked` mesure les clics vers un forfait après présentation du parcours.
- Un événement à zéro n’est pas automatiquement une panne : aucune action correspondante n’a peut-être eu lieu.
- Un pourcentage `NULL` signifie que son dénominateur est zéro.
- Ne jamais afficher ni consigner les `user_id`, `target_user_id`, courriels ou données astrologiques.
